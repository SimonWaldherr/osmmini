# Vendored microMap

Source: https://github.com/Karte-Bayern/microMap
Version: 0.3.0
Commit: 57e41ae403c916415ff779d9c17a77ea68523bb2
License: MIT (see LICENSE).

`micromap.mjs` is the upstream all-in-one ES module, generated by
`npm ci && npm run build` at the pinned commit. It contains the core, vector,
GeoJSON, camera, UI and MapLibre compatibility modules and has no external
runtime imports. Upstream `node tools/build.mjs --check` verified the supplied
bundle against its source. Source maps are omitted.

Run `make micromap-assets` to rebuild from the pinned upstream commit (requires
network, Git, Node.js 22+ and npm). `make ensure-micromap-assets` verifies the
committed files without network access.
