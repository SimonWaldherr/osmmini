                  GIS-Datenimport

                  GeoJSON, KML, KMZ oder Shapefile (als ZIP) als zusätzliche Kartenebene importieren. Reine Flächen-Layer werden automatisch auch als Gebietsebene nutzbar. Die Daten bleiben lokal auf diesem Server.

                  🧩

                  Eigene Kartenquelle (MBTiles / GeoTIFF)

                  Eine .mbtiles-Datei (Raster oder Vektor) oder ein georeferenziertes GeoTIFF (nur EPSG:3857/4326) als zusätzliche Kartenquelle "Eigene Quelle" importieren. Ein erneuter Import ersetzt die vorherige Datei; es gibt nur einen Speicherplatz. Vektor-MBTiles werden gespeichert, aber ohne automatischen Kartenstil.
